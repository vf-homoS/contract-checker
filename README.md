# Проверка договоров на юридические ошибки

Программа читает договор (.txt или .docx) и ищет опасные пункты: 100% предоплату без возврата, одностороннее изменение условий, автопродление, огромные неустойки и другое. По желанию нейросеть объясняет найденное простыми словами и предлагает безопасные формулировки.

> Программа не заменяет юриста. Важный договор стоит показать специалисту.

## Как запустить

1. Установи библиотеки:
   ```
   pip install -r requirements.txt
   ```
2. Запусти:
   ```
   python main.py                      # окно с кнопками
   python main.py договор.docx         # в консоли, только правила
   python main.py договор.docx --ai    # в консоли, правила + нейросеть
   ```

Попробовать можно на примере `sample_contract.txt`.

## Нейросеть

- **Ollama** — бесплатно, работает на твоём компьютере. Установи с [ollama.com](https://ollama.com) и выполни `ollama pull qwen2.5:3b`.
- **Claude** — платно, умнее. Положи ключ в переменную окружения `ANTHROPIC_API_KEY`. Ключ никогда не вписывай в код.

Если ключ Claude есть, программа берёт Claude, иначе Ollama. Выбрать вручную: `AI_PROVIDER=ollama` или `AI_PROVIDER=claude`.

## Файлы

- `main.py` — запуск: окно или консоль.
- `reader.py` — чтение .txt и .docx.
- `checker.py` — правила проверки.
- `ai_helper.py` — связь с нейросетью.
